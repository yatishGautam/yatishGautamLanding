01 Selected work

Production · Citi · Agentic AI

R2D2 — an LLM agent that speaks fluent treasury

A natural-language layer over CitiDirect transaction data. Type "payments to Acme over $50k last quarter" and R2D2 parses intent, extracts entities, generates structured queries, and synthesizes answers — a multi-step agentic pipeline running on sensitive financial data under a zero-trust security model.

No LangChain. No unapproved libraries. Tool-calling contracts, prompt templates, fallbacks, evals and observability — designed and built from scratch, because in a bank "it mostly works" isn't a feature.

  • Anthropic API
  • Python
  • Custom orchestration
  • Eval suites
  • Angular 19 MFE
